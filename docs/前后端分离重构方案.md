# 前后端分离重构方案

## 一、现状分析

### 1.1 当前架构

```
┌─────────────────────────────────────────────────────────┐
│                    demo.py (入口)                        │
├─────────────────────────────────────────────────────────┤
│  FastAPI + Gradio (混合)                                │
│  ├── /gradio  → Gradio UI (已废弃)                      │
│  ├── /ui      → Vue 静态文件 (frontend/dist)            │
│  └── /webrtc  → fastrtc WebRTC 端点                     │
├─────────────────────────────────────────────────────────┤
│  ChatEngine → HandlerManager → Handlers                 │
│  └── ClientHandlerRtc → RtcStream → WebRTC              │
└─────────────────────────────────────────────────────────┘
```

### 1.2 现有前端位置

| 路径 | 说明 | 状态 |
|------|------|------|
| `src/handlers/client/rtc_client/frontend/` | Vue 3 + Vite + TypeScript 前端 | 已存在，需迁移 |
| `src/third_party/gradio_webrtc_videochat/frontend/` | fastrtc 组件前端 | 保留（WebRTC 核心） |

### 1.3 需要删除的代码

| 文件/目录 | 原因 |
|-----------|------|
| `src/demo.py` 中 Gradio 相关代码 | 不再使用 Gradio UI |
| `src/handlers/client/rtc_client/frontend/` | 迁移至独立前端项目 |
| Gradio 依赖 (`import gradio`) | 后端不再需要 |

## 二、目标架构

```
┌────────────────────────┐     ┌────────────────────────────────┐
│   Vue 3 前端 (独立)     │────▶│   FastAPI 网关 (后端)           │
│   localhost:5173       │     │   localhost:8000               │
├────────────────────────┤     ├────────────────────────────────┤
│  - 面试配置页面         │     │  GET  /openavatarchat/initconfig │
│  - 数字人对话页面       │     │  POST /api/webrtc/offer        │
│  - WebRTC 客户端        │     │  POST /api/webrtc/ice          │
│  - 状态管理 (Pinia)     │     │  WebSocket (可选)              │
└────────────────────────┘     ├────────────────────────────────┤
         │                     │  ChatEngine                    │
         │ WebRTC              │  └── Handlers (ASR/LLM/TTS/Avatar)
         │ 信令 + 媒体流        │  └── RtcStream (WebRTC 核心)    │
         ▼                     └────────────────────────────────┘
    ┌─────────────┐
    │  浏览器      │
    │  音视频流    │
    └─────────────┘
```

## 七、风险与注意事项

1. **CORS 配置** - 前后端分离需要配置跨域
2. **HTTPS 要求** - WebRTC 需要安全上下文（localhost 除外）
3. **TURN 服务** - 公网访问仍需 TURN 服务器
4. **现有前端代码** - 可复用 `rtc_client/frontend/src/` 中的 WebRTC 逻辑

## 十、启动说明

### 后端启动

```bash
# 进入项目目录
cd d:\Projects\OpenAvatarChat

# 启动后端服务（默认端口 8000）
uv run src/demo.py --config config/chat_with_openai_compatible_bailian_cosyvoice.yaml
```

### 前端启动

```bash
# 进入前端目录
cd d:\Projects\OpenAvatarChat\frontend

# 安装依赖
pnpm install

# 启动开发服务器（默认端口 5173）
pnpm dev
```

### 访问地址

- **前端开发服务器**: http://localhost:5173
- **后端 API**: http://localhost:8000
- **WebRTC 配置**: GET http://localhost:8000/openavatarchat/initconfig

### API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/openavatarchat/initconfig` | GET | 获取 WebRTC 和数字人配置 |
| `/webrtc/offer` | POST | WebRTC 信令（fastrtc 提供） |
